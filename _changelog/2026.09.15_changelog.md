# Changelog — 2026.09.15

## Session: Unified signal model ported from Quantactic, core engine bug fixes, QRM 3.0 contracts (15:39)

### Added
- Unified signal model — every user-facing surface resolves to exactly one of `BUY` / `WAIT` / `SELL` plus a seven-category evidence list that explains it, instead of reconciling four scales (decision, setup quality, setup type, regime) at each call site. (`src/shared/unifiedSignal.ts`)
- Gate-based conclusion resolution — a missing trigger, unusable risk plan, blocking event risk, or two contradicting categories hold the conclusion at `WAIT` regardless of setup quality. Strength is capped at 74 for a `WAIT` and floored at 55 for a decided conclusion so the number cannot contradict the word beside it. (`src/shared/unifiedSignalResolver.ts`)
- Price Acceptance and estimated volume-at-price — each bar's volume is distributed across the range it traded through rather than onto its close, yielding a point of control and 70% value area. Acceptance requires completed closes beyond a boundary, ATR-measured distance, and participation, so price *printing* through a level is no longer read as a breakout. Quant had no acceptance concept at all. (`src/shared/volumeProfile.ts`)
- Wilder-smoothed indicator math — series-returning ATR, RSI, EMA and MACD aligned to the candle series, so a replay can read the value as it stood at any bar. (`src/shared/indicators.ts`)
- Raw factor layer with fixed per-kind polarity, so evidence can state what price is doing independently of the conclusion being argued. A factor kind that reaches no evidence category fails to compile. (`src/shared/signalFactors.ts`)
- Evidence aggregation and reason prioritisation — raw factors consolidate into stable categories, so adding an indicator makes a row better informed rather than making the screen longer; at most two reasons reach a collapsed card. (`src/shared/signalEvidenceAggregator.ts`, `src/shared/signalReasonPrioritizer.ts`)
- QRM-3 research contracts and the experimental decision functional from `docs/quant-v3/05`, including the section 12 entry-location metric. Gates on forward asymmetry rather than a trailing score, which is what makes a peak entry structurally hard to produce. (`src/shared/qrm.ts`, `src/shared/qrmDecision.ts`)
- Kronos-to-QRM distribution adapter and neutral `ResearchModelView` renderings; the two models keep their native semantics and a disagreement is surfaced rather than averaged. (`src/shared/kronosDistribution.ts`)
- 13-part test suite for the above, wired as `npm run test:unified`. (`scripts/test-unified-signal.mjs`)

### Changed
- `SignalDeskResult` now carries `unified` alongside `evaluation`. The raw deterministic evaluation is unchanged and still feeds the harness, journal and replay; `unified` is what a surface should render. (`src/shared/signalV2.ts`, `src/main/services/signalDesk.ts`)
- Signal Desk cache key includes the unified model version, so bumping the resolver invalidates cached conclusions. (`src/main/services/signalDesk.ts`)
- The experimental mobile decision policy was **not** ported as originally drafted. `docs/quant-v3/05` forbids copying it into desktop production, so the first pass (`forecastSignalPolicy.ts`) was deleted and re-derived against that document's contracts and thresholds (0.25 signal-to-noise, 0.60 directional probability, 1.30 reward/risk).

### Fixed
- `breakout` setup was unreachable — `nearestResistance` fell back to the highest high of the trailing window *including the bar being evaluated*, so any push to a new high returned that bar's own high, a level the close is under by construction → `close > resistance` was unsatisfiable, and the fraction-of-a-percent distance vetoed genuine breakouts as "too close to resistance for a long trade" → structure levels now come from closed bars only via `swingHigh`/`swingLow`, and `null` means price has cleared everything overhead. (`src/shared/quant.ts`)
- `getForwardSummary` reported the wrong `firstSignalAt` / `lastResolvedAt` — read off array positions that stop being chronological once the store is pruned → both are now reduced over the values. (`src/main/services/signalOutcomeStore.ts`)
- Forward-outcome pruning discarded the newest resolved records — a prior prune rewrites the file as `[unresolved…, resolved…]`, after which slicing the tail no longer selects the most recent → records are sorted by signal bar time before pruning. (`src/main/services/signalOutcomeStore.ts`)
- `npm run typecheck` failed on the `logoQuant.png` import — no ambient declarations for the assets esbuild inlines as data URLs → added them. (`src/types/assets.d.ts`)
- Removed an unused `DEFAULT_EXECUTION_CONFIG` import. (`src/shared/signalValidation.ts`)

## Session: Quant 3.0 plans 01-05 implemented (16:50)

### Added
- **Plan 01 — persistent session-aware market data.** Main-process cache under `market-cache-v3` with gzip payloads, hashed manifest, atomic temp-and-rename writes, oldest-first pruning to 512 MiB and orphan sweeping; renderer keeps an L1 memory map only. Session classification is pure and DST-correct via `Intl.DateTimeFormat`. (`src/main/services/marketCache.ts`, `src/main/services/chartRepository.ts`, `src/shared/marketSession.ts`)
- **Plan 02 — chart workspace, events, immutable signal history.** Provider-neutral event boundary over five offline-tested parsers plus a bundled FOMC fallback; non-causal event reaction engine; append-only signal history with a guarded one-time v2 import; session-aware header, extended-hours layer, viewport-filtered marker layers, and the `chart-v3/` workspace shell. (`src/main/services/economicEvents.ts`, `src/main/services/events/`, `src/shared/eventReaction.ts`, `src/main/services/signalHistoryStore.ts`, `src/renderer/components/chart-v3/`)
- **Plan 03 — portfolio, risk, exposure.** Validated local store with backup recovery; exact aggregation where a missing price is null rather than zero; risk with date intersection, empirical VaR/CVaR and cash as a zero-volatility sleeve; look-through exposure reported as a floor with coverage; CSV import with a mapping preview that lists every rejected row and its reason; Portfolio page and chart Position inspector. (`src/shared/portfolio*.ts`, `src/main/services/portfolio*.ts`, `src/renderer/components/portfolio/`)
- **Plan 04 — discovery and attention.** Background universe hydrator with persisted progress and per-symbol backoff; robust median/MAD features and beta-adjusted residuals; grouped and capped attention components; change-based novelty with a persisted snapshot history; two-stage scan where the expensive replay runs only on the deep slice; Discover and Today pages. (`src/shared/discovery*.ts`, `src/main/services/universeHydrator.ts`, `src/main/services/discoveryDeepScan.ts`, `src/renderer/components/discovery/`)
- **Plan 05 — QRM-3.** Point-in-time state builder, leakage-safe analogue records, ESS-targeted kernel bandwidth, seeded stationary block bootstrap, forecast assembler, walk-forward benchmark with three baselines and promotion gates, worker-thread compute service, and the Research Lab page. (`src/shared/qrm*.ts`, `src/main/services/qrmService.ts`, `src/main/workers/qrmWorker.ts`, `src/renderer/components/lab/`, `scripts/qrm-research-loop.mjs`)
- Eight new test suites: `test:market-data-v3`, `test:chart-v3`, `test:events-v3`, `test:signal-history-v3`, `test:portfolio-v3`, `test:portfolio-risk-v3`, `test:discovery-v3`, `test:qrm-v3`.
